# 利用規約

TenkaCloud (以下「本サービス」) の有料プラン (= Starter / Hosted Event / Annual Arena) をご利用いただく際の利用規約。OSS としての利用 (= 自前 AWS 環境へ deploy する自己ホスト) は Apache License 2.0 が優先します。

最終更新: 2026-05-23 · 運営: 合同会社BULL

## 第 1 条 (適用)

本規約は、お客様 (= 法人または個人) と本サービス運営者 (以下「当社」) の間の、有料プランの提供に関するすべての関係に適用されます。個別の見積書 / 契約書がある場合は、そちらが優先します。

## 第 2 条 (有料プラン)

- **Starter** (50 万円 / 回、税別): 1 回 / 2 チームまでのお試しイベントを当社が運営代行。
- **Hosted Event** (150 万円 / 回、税別): 1 回 / 5 チーム (〜 20 人) のイベントを構築から当日進行まで運営代行。
- **Annual Arena** (600 万円 / 年〜、税別): 年間契約で年 4 回のイベント開催を代行 + 公開問題カタログから learning path 提案 + 事後レポート PDF。

カスタム問題の追加開発、業界特化シナリオ、20 人超の同時開催等は別途お見積もり対応。

## 第 3 条 (申込・契約成立)

お客様が当社のお問い合わせフォームよりプランをお申し込みいただき、当社が見積書を発行、双方の合意 (= 書面 / メール) をもって契約成立とします。

## 第 4 条 (支払い)

- **支払い方法**: 銀行振込 (= 当社指定口座、振込手数料はお客様負担)。
- **支払時期**: 請求書発行から 30 日以内。
- **遅延損害金**: 年 14.6% (= 商事法定利率)。

## 第 5 条 (お客様の責務)

- 本サービスが deploy する AWS リソースはお客様の AWS アカウント内に作成されます。AWS アカウントの管理 (= IAM / 課金 / 監査ログ) はお客様の責任。
- イベント参加者への連絡、参加者の AWS Console SSO ログイン操作の利用規約遵守 (= 参加者個人の AWS アカウントは不要 / 主催者環境のみに federate) はお客様の責務。
- 本サービスが提供する一時的な AWS 認証情報の取り扱いは、参加者にも周知する。

## 第 6 条 (当社の責務)

- 有料プランの仕様に沿った構築・進行・事後レポート PDF (= 1 イベント 1 部) を成果物として提供。
- イベント期間中の障害対応 (= 当社起因の deploy 失敗、ポータル不具合等) は best-effort で速やかに対応。
- SLA は明示的に規定しない (= OSS ベースのため)。重大障害の場合は協議の上対応する。

## 第 7 条 (禁止事項)

お客様は以下を行ってはなりません。

- 本サービスを通じて、違法な行為 (= 不正アクセス、著作権侵害 等) を行うこと。
- 当社の知的財産権 (= ロゴ等。OSS コード自体は Apache 2.0) を無断で使用すること。
- 参加者から取得した個人情報を、イベント運営目的外で利用すること。

## 第 8 条 (免責)

- 当社は、イベント開催により参加者または第三者に発生した損害について、当社の故意または重大な過失に起因する場合を除き、責任を負いません。
- 本サービスが deploy する AWS リソースに伴う AWS 利用料金 (= お客様アカウントに直接課金) は、お客様の負担となります。当社は AWS 料金については一切責任を負いません。
- イベント参加者の AWS Console 操作による意図せざる課金 / 設定変更 / リソース削除についても同様です (= 当社は IAM の最小権限設計を推奨)。

## 第 9 条 (中途解約)

- Annual Arena の中途解約は、残期間相当の費用を返金しない (= 年間契約の特性上)。ただし双方協議で例外可。
- Starter / Hosted Event は、イベント開催 30 日前までキャンセル無料、30 日前 〜 7 日前 50% 支払い、7 日前以降 100% 支払い。

## 第 10 条 (準拠法・管轄)

本規約は日本国法に準拠し、本サービスに関する一切の紛争は、合同会社BULL の本店所在地を管轄する裁判所を専属的合意管轄裁判所とします。

## 第 11 条 (改定)

当社は、法令の変更や本サービスの内容の変更に応じて、本規約を改定することがあります。重要な改定がある場合は、30 日前までに本ページまたはメールでお知らせします。

OSS 自己ホストの場合 (= Apache License 2.0) は本規約は適用されず、ライセンス本文 (`LICENSE`) が適用されます。
