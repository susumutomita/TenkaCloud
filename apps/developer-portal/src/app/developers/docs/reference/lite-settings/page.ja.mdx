[元の設定とメッセージ](https://github.com/susumutomita/TenkaCloud/tree/825415fcda5075ad723daf9e4514eac47d7b8bb9/apps/developer-portal/src/app/developers/docs/reference/lite-settings)は旧 CDK/Lambda 基盤の資料です。現在のローカル大会 host の設定ではありません。旧 DynamoDB/Turso のデータは新しい保存領域と同期されません。自動移行も行いません。

<h2 id="current-guidance">現在の手順</h2>

[はじめに](/developers/docs/getting-started/)、[開催者マニュアル](/developers/docs/manual/organizer/)、[配置の境界](/developers/docs/operate/deploy-paths/)を使います。現在の AWS 配置 role の ExternalId は必須で、host ごとに保存します。長さは 16–128 文字、半角英数字と `_ = , . @ : / -` を使います。初期設定には現在のコンソールが示す正確な値を使ってください。
