# runtime の実行状況 <MaturityBadge level="preview" />

<h2 id="matrix">現行 candidate</h2>

| Runtime | 現在の境界 |
| --- | --- |
| ローカル Docker Compose | ローカル開催専用で、クラウドのカタログには表示しない。新しい大会は最大 512 件の停止中 jobs を準備。参加者が起動・再開・停止する。デフォルトはチーム 3、host 全体 12 環境、メモリー上限の合計 4096 MiB。106 問の表示は全問のプレイ確認ではない |
| Docker 問題内の terminal | 15 問が宣言。実 PostgreSQL terminal の exec、3 checkpoints、チーム分離、再起動を確認。他の terminal 問題には追加の代表経路確認が必要 |
| 組み込みの Cryptography Battle | 確認した ac26-crypto-battle は得点を奪う機能が無効なら競技者アカウント不要。有効時は AWS 版を維持。ローカル SQLite またはクラウド Turso / DynamoDB。旧 coordination の非公開チーム表示と採点。両クラウド DB とも 99 チーム、SQL state は 4 MiB。実環境の大会性能は未検証 |
| AWS CloudFormation | クラウド開催専用。別の検証済み競技者アカウントが必要で、hosting account は変更前に拒否。create / update / no-op / recreate、flag / multi-flag・定期採点、参加者 Console / CLI を復旧。現行 catalog の 9 template は TemplateBody の 51,200 bytes を超え、TemplateURL は未実装。実 AWS は別途リハーサル |
| Lambda + Turso/DynamoDB のクラウド基盤 | 旧 Lite の基盤、Lambda / CodeBuild の配置経路、組み込み Battle と make deploy/destroy CLI を復旧。標準 CDK bootstrap を使い、保存した catalogKey と非公開 source archive の key / VersionId を更新後も維持。Docker / Compose 問題はローカル開催専用 |
| 外部 pack、Azure、GCP、Sakura、その他の採点方式 | schema・作問用の宣言だけでは大会での実行対応になりません |

<h2 id="support-classes">確認結果を区別する</h2>

metadata の受理、一覧への表示、adapter 接続、fixture テスト、実 Docker・ブラウザ、実クラウドの確認はそれぞれ別です。[配置の境界](/developers/docs/operate/deploy-paths/)を確認し、通していない経路は Not run と記録してください。
