# Manuals by role <MaturityBadge level="preview" />

<h2 id="choose-your-role">Choose your role</h2>

- [Organizer](/developers/docs/manual/organizer/): prepare teams, environments, invitations, scoring and cleanup
- [Participant](/developers/docs/manual/participant/): join your team and solve its assigned problems
- [Problem author](/developers/docs/manual/problem-author/): write content and verify the participant route
- [Developer](/developers/docs/manual/developer/): change the implementation and its tests

<h2 id="how-the-roles-fit-together">How the roles fit together</h2>

One local process serves organizer and participant applications, persists event/team state and controls owned exercise environments. Organizer permissions and team authentication are separate. Authors own catalog content; schema acceptance alone does not establish runtime support.

<h2 id="if-you-are-unsure">If you are unsure</h2>

Start with [getting started](/developers/docs/getting-started/). The candidate has no current SaaS/Lite setup path; cloud deploy/destroy use the current CLI after reviewed IAM setup. The cloud catalog includes hello-world and native Cryptography Battle; container-based cloud execution remains incomplete and Battle capacity is under verification.
