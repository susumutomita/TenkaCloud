# Problem packs <MaturityBadge level="stable" />

A **problem pack** is the unit of competition content on TenkaCloud.

## What is a problem pack

Each pack carries metadata, a single-page CloudFormation template deployed
straight into a competitor account, and an optional portal plugin.

## Battle versus Challenge

- **Battle** packs are real-time and head-to-head.
- **Challenge** packs are self-paced and evergreen.

## Scoring kinds

Scoring uses one of six built-in kinds — `flag`, `multi-flag`, `uptime-flat`,
`uptime-multi`, `phased-polling`, or `attack-detection` — one per problem.
