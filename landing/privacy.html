プライバシーポリシー

TenkaCloud (以下「本サービス」) における個人情報の取扱いについて。

最終更新: 2026-07-31 · 運営: 合同会社BULL

1. 取得する情報

本サービスの提供および商談対応のため、以下の情報を取得することがあります。

  • お問い合わせ情報: お名前、 所属組織、 連絡先メールアドレス、 お問い合わせ種別、 お問い合わせ本文 (= Google フォームで取得)。 フォームは本サイト上に設置しているが、 入力内容はブラウザから Google のサーバーへ直接送信され、 本サービスのインフラを経由しない。
  • 運営者アカウント情報: 本サービスにサインインする運営者 (システム管理者 / テナント管理者 / オペレーター) のメールアドレスおよびユーザー名。 認証基盤である Amazon Cognito に保存される。
  • 操作監査ログ: 運営者の操作履歴として、 操作者の識別子 (Cognito sub) とユーザー名 (= メールアドレス)、 操作内容・対象・結果、 アクセス元 IP アドレス・User-Agent、 日時を記録する。 セキュリティ監査および不正アクセス調査のために保管する。
  • イベント運営代行に伴う情報: お客様が運営するイベントの参加者情報 (= チーム名 / 表示名)、 提出ログ、 スコア履歴等。 本サービスの SaaS インフラ (= AWS) 上に保存され、 イベント終了後 7 日経過で自動削除される。 なお参加者個人のアカウント (氏名 / メール) は作らず、 チーム単位の短命キーで認証する設計のため、 参加者個人を直接識別する情報は収集しない。
  • アクセスログ: ランディングページおよびポータルへのアクセスに伴う IP アドレス、 User-Agent、 リファラ等。 GitHub Pages / Amazon CloudFront のアクセスログとして 標準保管される。
  • ブラウザ体験版の操作データ: オンボーディングの表示パターン、 表示したステップ、 ヒント公開、 提出結果、 完了までの時間。 回答文字列・flag・チームキーは Google アナリティクスへ送信しない。

2. 利用目的

  • お問い合わせへの返信および見積もり提示。
  • 本サービスの運営、 障害対応、 セキュリティ監査。
  • 本サービスの改善に伴う 統計的分析 (= 個人を特定しない形)。
  • 法令に基づく対応 (= 警察 / 裁判所 等からの正当な要請)。

3. 第三者提供

あらかじめお客様の同意を得た場合、 または法令に基づく場合を除き、 個人情報を第三者に提供することはありません。 ただし以下のクラウドサービス提供者にデータが保存されることがあります (= いずれもインフラとしての利用、 内容を読み取られることは想定していない)。

  • Amazon Web Services, Inc. (= 本サービスの SaaS インフラ提供者)
  • GitHub, Inc. (= ランディングページ配信、 OSS リポジトリ提供者)
  • Google LLC (= お問い合わせフォームの回答保存、 ランディングページおよびブラウザ体験版のアクセス解析)

4. 保管期間

  • お問い合わせ情報: 商談終了後 2 年間。
  • 運営者アカウント情報: アカウントが削除されるまで。
  • 操作監査ログ: 既定 90 日間。 SOC2 等の要件に対応するホスト型プランでは 365 日間 (= AUDIT_RETENTION_DAYS で設定)。 経過後は自動削除されます。
  • イベント運営代行の参加者データ: イベント終了後 7 日間。 経過後は自動削除されます。
  • アクセスログ: AWS / GitHub の標準保管期間に従う。

5. 開示・訂正・削除請求

お客様ご自身の個人情報について、 開示・訂正・削除のご請求はお問い合わせ窓口までご連絡ください。 本人確認の上、 法令に基づき速やかに対応します。

6. Cookie / トラッキング

本ランディングページとブラウザ体験版 (portal-demo) はアクセス解析およびオンボーディング改善のため Google アナリティクス 4 (gtag.js) を使用し、 _ga 等の Cookie を設定します。 閲覧ページ・おおよその地域・デバイス / ブラウザに加え、 体験版では表示パターン、 ステップID、 ヒント公開、 提出結果、 完了までの時間を Google LLC に送信します (同社が当方に代わり処理)。 回答文字列・flag・チームキーは送信せず、 集計的な導線分析のみに使用します。 本番の参加者ポータルはこの Google アナリティクス計測を読み込みません。 体験版はA/B表示の割り当てとセッション管理のため localStorage を使用します。 ブラウザ設定または Google のオプトアウトアドオンで無効化できます (= 2026-07 時点)。

7. 改定

本ポリシーは、 法令の変更や本サービスの内容の変更に応じて改定されることがあります。 重要な改定があった場合は、 本ページに掲載することで お知らせとします。

8. お問い合わせ窓口

個人情報に関するお問い合わせは、 以下までご連絡ください。

  • 窓口: 合同会社BULL (TenkaCloud 運営)
  • 連絡方法: GitHub Discussions または LP のお問い合わせフォーム
