プライバシーポリシー

TenkaCloud (以下「本サービス」) における個人情報の取扱いについて。

最終更新: 2026-05-23 · 運営: 合同会社BULL

1. 取得する情報

本サービスの提供および商談対応のため、以下の情報を取得することがあります。

  • お問い合わせ情報: お名前、 所属組織、 連絡先メールアドレス、 お問い合わせ本文。
  • イベント運営代行に伴う情報: お客様が運営するイベントの参加者情報 (= チーム名 / 表示名)、 提出ログ、 スコア履歴等。 本サービスの SaaS インフラ (= AWS) 上に保存され、 イベント終了後 7 日経過で自動削除される。
  • アクセスログ: ランディングページおよびポータルへのアクセスに伴う IP アドレス、 User-Agent、 リファラ等。 GitHub Pages / Amazon CloudFront のアクセスログとして 標準保管される。

2. 利用目的

  • お問い合わせへの返信および見積もり提示。
  • 本サービスの運営、 障害対応、 セキュリティ監査。
  • 本サービスの改善に伴う 統計的分析 (= 個人を特定しない形)。
  • 法令に基づく対応 (= 警察 / 裁判所 等からの正当な要請)。

3. 第三者提供

あらかじめお客様の同意を得た場合、 または法令に基づく場合を除き、 個人情報を第三者に提供することはありません。 ただし以下のクラウドサービス提供者にデータが保存されることがあります (= いずれもインフラとしての利用、 内容を読み取られることは想定していない)。

  • Amazon Web Services, Inc. (= 本サービスの SaaS インフラ提供者)
  • GitHub, Inc. (= ランディングページ配信、 OSS リポジトリ提供者)

4. 保管期間

  • お問い合わせ情報: 商談終了後 2 年間。
  • イベント運営代行の参加者データ: イベント終了後 7 日間。 経過後は自動削除されます。
  • アクセスログ: AWS / GitHub の標準保管期間に従う。

5. 開示・訂正・削除請求

お客様ご自身の個人情報について、 開示・訂正・削除のご請求はお問い合わせ窓口までご連絡ください。 本人確認の上、 法令に基づき速やかに対応します。

6. Cookie / トラッキング

本ランディングページ自体は Cookie を設定しません。 ただし参加者ポータル (= portal-demo / 本番ポータル) は、 セッション管理のため localStorage を使用します。 トラッキング目的の Cookie / 解析ツールは使用していません (= 2026-05 時点)。

7. 改定

本ポリシーは、 法令の変更や本サービスの内容の変更に応じて改定されることがあります。 重要な改定があった場合は、 本ページに掲載することで お知らせとします。

8. お問い合わせ窓口

個人情報に関するお問い合わせは、 以下までご連絡ください。

  • 窓口: 合同会社BULL (TenkaCloud 運営)
  • 連絡方法: GitHub Discussions または LP のお問い合わせフォーム

準拠法: 日本国法 · 管轄裁判所: 合同会社BULL の本店所在地を管轄する裁判所
