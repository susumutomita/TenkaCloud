特定商取引に関する法律 第 11 条 に基づく事業者情報の表示。

最終更新: 2026-05-23

販売事業者 合同会社BULL
代表者 代表社員 冨田進
所在地 請求があった場合に遅滞なく開示します。 お問い合わせよりご連絡ください。
連絡先 GitHub Discussions または LP お問い合わせフォーム よりご連絡ください。
販売価格 各プランの価格は トップページの料金セクション に表示しています。 すべて税別表示です。
  • Starter: 50 万円 / 回
  • Hosted Event: 150 万円 / 回
  • Annual Arena: 600 万円 / 年〜
AWS 利用料金 (= お客様アカウントに直接課金) は別途、 お客様負担となります。
商品代金以外の必要料金 振込手数料 (= お客様負担)。 AWS 利用料金 (= お客様の AWS アカウントへ直接課金、 当社を経由しない)。
支払方法 銀行振込 (= 当社指定口座)。 請求書 を発行します。
支払時期 請求書 発行から 30 日以内。
商品引渡し時期 (= 役務提供時期) 個別の見積書 / 契約書に記載されたイベント開催日 / 期間に従い、 当社が運営代行および事後レポート PDF を提供します。
返品・キャンセル
  • Starter / Hosted Event: イベント開催 30 日前までキャンセル無料、 30 日前 〜 7 日前で 50% 支払い、 7 日前以降は 100% 支払い。
  • Annual Arena: 年間契約の特性上、 中途解約による返金は行わない (= ただし双方協議で例外可)。
詳細は 利用規約 第 9 条をご確認ください。
動作環境 主催者側: 自前の AWS アカウント (= リソース deploy 先)、 モダンブラウザ (Chrome / Edge / Safari の最新版)。
参加者側: モダンブラウザのみ (= AWS アカウント不要、 主催者環境へ federate)。

OSS としての利用 (= 自前 AWS に deploy する自己ホスト、 Apache License 2.0) には、 本表記および 利用規約 は適用されません。
