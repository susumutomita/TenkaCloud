TENKACLOUD とは

チームで環境を直し、
その場で採点されるクラウド演習です。

主催者は1つの画面で、大会・チーム・問題・ヒント・採点を管理します。参加者はポータルの URL とチームキーで入り、問題を解いて提出します。

GameDay 型のチーム戦
用意された環境を時間内に直す。定期的なチェックで、直した状態が点数になる。
CTF 型のフラグ問題
答え（Flag）を探して提出する。正解すると、その場でスコアボードが動く。

Apache-2.0 の OSS。セルフホストでき、ソースはすべて GitHub で公開しています。

TenkaCloud とは2 / 10

どこで動くか

本体は PC 1台か AWS に。
演習は4つのクラウドに出せます。

TenkaCloud 本体

PC 1台データは SQLite に保存。AWS アカウントは不要。

AWSLambda・Cognito と、Turso か DynamoDB。

演習の環境（チームごとの認証情報）

  • AWS
  • Google Cloud
  • Azure
  • さくらのクラウド

1つの問題で、複数のクラウドに同時に展開することもできます。PC 上の Docker 演習も使えます。

参加者は社内 LAN や Tailscale 経由で、自分の端末から参加します。別の端末から Docker 演習に参加するには、Linux の開催 PC と分離の設定が必要です（事前に一緒に確認します）。

演習の例4 / 10

なぜパートナーを探しているか

作り手だけでは、
分からないことがあります。

  1. 問題の難しさは、受講者に合っているか。
  2. 開催者の準備は、どこで止まるか。
  3. 社内ネットワークの条件で、参加者がつながるか。
  4. 採点の記録は、ふりかえりに使えるか。

答えは、実際の研修や勉強会でしか出てきません。

なぜ募集するか5 / 10

パートナーになると

一緒に1回、開催してみませんか。

私たちがすること

  • 準備から当日まで一緒に入る。問題選び、開催 PC の準備、リハーサル、当日の進行。
  • 出てきた不具合や要望を優先して検討する。直したものは OSS として公開します。
  • 問題づくりの相談に乗る。自分たちのシステムに近い題材から作れます。

お願いしたいこと

  • 実際の研修か勉強会で、1回開催する。2チームほどの小さな回で十分です。
  • 終わったあと、30分のふりかえりに付き合う。採点の記録を見ながら話します。
  • 気づいたことを、良くも悪くもそのまま伝える。GitHub Issue でもメールでも。

事例として紹介してよいかは、開催のあとで相談させてください。OSS なので、終わったあとも自分たちで開催を続けられます。
