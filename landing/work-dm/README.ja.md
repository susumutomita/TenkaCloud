# そのお願い、聞いていい？ — めくって、カードで撃つ

採用依頼の見せかけをはがし、独立して確認した公式案内と違う要求を見破る固定画面ゲームです。
文章回答の選択や、カードを選んで別の射撃ボタンへ移動する手順はありません。

## 操作しながら覚える

最初の 1 枚は操作練習です。得点も時間制限もありません。
こすって開くと、表の「画面テスト」に対して裏は「APP 実行」、公式は「Web だけ」という比較をその場で示します。
開いたカードを直接タップして撃ち、同じ練習欄から本番 4 枚へ進みます。練習の得点は本番に入りません。

本番は横こすりかタップで開き、怪しいと判断した開いたカードを直接タップして撃ちます。
キーボードでは Enter / Space で同じカードを開き、指やキーを離してからもう一度押して撃ちます。
開いた直後 500 ミリ秒のクリック、ダブルクリックの連続打鍵、移動・キャンセルしたポインターのクリックは射撃に使いません。
誤って開いた操作の続きが射撃として扱われないようにし、抑制した入力による減点はありません。

## 本番の採点と終了

- 偽装は 2 つ。正しい遮断は各 50 点で、満点は 100 点。
- 公式案内と一致するものへの誤射は初回のみ −25 点。全部撃っても 50 点。
- 開く操作だけは 0 点。同じカードの連打は重複処理なし。
- 4 枚の中身を見たら「調査完了」で結果へ。能動時間 2 分の時間切れでは部分点を維持し、無操作は 0 点。
- 一時停止・非表示タブでは時計を停止。安全な保留で終える場合は採点なし。
- 終了後の加点は禁止。再挑戦は本番から開始し、スコア・照準なしのカード状態・時計・入力抑制を初期化。

小画面では縦スクロールを使います。はがしたカードは中央へ寄せ、比較する公式案内は見える位置に残します。
本件の根拠は、明示された「Web だけ」「提出先は aoba.example だけ」という公式の約束との矛盾です。
外部サイトやアプリ一般を悪性と扱わず、残したカードも安全性全般の保証とはしません。
結果の X 共有は投稿画面を開くだけで、最終投稿は本人の操作です。

## 試作の限界

すべて架空の静的表示です。実際の送信・ダウンロード・インストール・実アカウント操作はありません。
X リンクだけは、押した本人の操作で結果と現在のゲーム URL を投稿画面へ渡します。
楽しさ、初見の所要時間、学習効果、実機 Safari は利用者による評価が必要です。

## 連絡の場面

架空の仕事 SNS「WorkSquare」で、予約ページの公開作品を見たスカウトから始まります。
仕事内容・週 3 日のリモート勤務・火曜 17 時の面談に合意した履歴を、短い既読要約と任意の会話表示で示します。
現在の依頼は模擬 DM と電話着信の見た目で提示します。電話は音声なしの字幕だけで遊べます。
採用案内から独自のスキルチェックサイトへ進み、環境をそろえるという口実でアプリ実行を求める場面が軸です。
電話でも以前の SNS の話をつなぎ、面談前の提出を頼むことで信用形成を表現します。

SNS・電話はそれぞれに正当な連絡と矛盾する要求を 1 件ずつ含めます。媒体や自然な会話だけで悪性・安全とは判定しません。
履歴を開いている間は時計を停止し、閉じるかカードを操作すると再開します。履歴を開くことは採点の条件ではありません。
会話・会社・候補者の作品はすべて架空であり、実際の個人情報や受信メールは転用していません。
