# そのお願い、聞いていい？ — 証拠をつなぐ調査ゲーム

架空の採用 DM、プロフィール、選考サイト、独立して開いた公式採用情報を触って調べる、1 事件の試作です。
文章の回答選択や、どの段階で止めたかの採点はありません。

## 操作

1. 気になる箇所をタップし、証拠カードとして保存する。
2. 証拠台で 2 枚を選んでつなぐ。
3. つながった証拠を選び、DM の依頼に突きつける。

スマホもタップのみで同じ操作ができます。キーボードでは Tab と Enter / Space を使います。
情報源は最初から開けます。公式情報は相手のリンクではなく、自分で調べたページという模擬設定を明示します。

## 採点と終了

- 2 つの具体的な矛盾を突きつけると、それぞれ 50 点。合計 100 点。
- 保存・閲覧だけでは加点なし。未接続の証拠は提示不可。
- 矛盾を示さない組み合わせは初回だけ −10 点。同じ組み合わせの連打は重複処理なし。
- 3 回の誤接続、または能動時間 2 分で終了。無回答は 0 点、得た部分点は維持。
- 2 つを突きつけても終了。終端後の加点は禁止し、再挑戦ではすべての状態を初期化。
- 非表示タブでは時計を停止。証拠を読む・比較する操作はプレー時間に含む。残秒の数字は常時表示しない。

根拠は、試験サイトの場所とアプリの実行要求が、明示された公式の試験方針と食い違うことです。
締切や職種が同じことは矛盾ではありません。未知の相手・外部サイトというだけでは悪性と扱いません。
終了後に実際の該当箇所を比較し、安全な次の行動を解説します。回答前の正解ハイライトはありません。

## 安全と試作範囲

すべて同じ静的ページ内の模擬表示です。実通信、外部遷移、ファイル取得・実行、アカウント操作はありません。
架空の会社・人物と予約済み `.example` ドメインのみを使用します。
今回は 1 事件のみで、問題一覧登録・残りの場面・X 共有は含めません。
1〜3 分で遊ぶ設計ですが、初見の所要時間・楽しさ・学習効果は利用者の評価が必要です。
