# そのお願い、聞いていい？ — 仮面をはがす固定画面シューティング

架空の採用担当から渡された 4 つのタスクを、こすってはがし、実際の動作を見抜く 1 場面の試作です。
落下する文章、会話の回答選択、証拠カードの照合、停止時点の当てっこはありません。

## 操作

1. ラベルを横にこすってはがす。タップ、またはキーボードの Enter / Space でも同じ操作。
2. 中に出た大きな Web / APP 表示と提出先を、独立して確認した公式の約束と比べる。
3. 偽装と思ったタイルに狙いを合わせ、下のボタンで撃ち抜く。
4. 4 つの中身を見たら「調査完了」で結果へ。

正解は割れて弾け、誤射はその場で反応します。減動作設定では短い静的反応に置き換えます。
小さな URL の文字を高速で狙う必要はありません。位置は再挑戦ごとに抽選します。

## 採点と安全な中断

- 根拠のある偽装の遮断は各 50 点、2 つで 100 点。
- 公式案内と一致するタスクへの誤射は初回のみ −25 点。全部撃っても 50 点であり、満点にはならない。
- はがすだけ・狙うだけは加点なし。同じタイルの連打は重複処理なし。
- 能動時間 2 分の時間切れでは得た部分点だけを維持。無操作は 0 点。非表示タブと一時停止中は時計を停止。
- 「一時停止」から安全に保留して終了した場合は採点なし。実行前の安全な中断を失敗扱いしない。
- 終了後は加点禁止。再挑戦ではスコア、照準、演出、時計を初期化。

本件の根拠は、明示された「Web だけ」「提出先は aoba.example だけ」という公式の約束との矛盾です。
外部サイトやアプリ一般を悪性と扱いません。残したタスクも、安全性全般を保証するものではありません。
終了後に短い理由と安全な次の行動を表示します。X 共有は本人の操作で投稿画面を開くだけで、投稿は本人が行います。

## 安全と未確認

すべて静的な模擬表示です。実通信、外部遷移、ファイル取得・実行、実アカウント操作はありません。
X の共有リンクだけは、押した本人の操作で結果とゲーム URL を投稿画面へ渡します。
架空の会社・人物と予約済み `.example` ドメインのみを使用します。
初見の所要時間、楽しさ、学習効果、バズるかはテスト数からは分かりません。今回の 1 場面を実際に遊んで評価する試作です。
