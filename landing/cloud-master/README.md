# APIの番人。 — 目指せクラウドマスター

Frontend-only defensive game at `/cloud-master/`. Protect a synthetic production
AWS environment: tap suspicious operations; let normal operations pass. Cards show
decisive SDK input excerpts plus resource, purpose or baseline context. No AWS
request executes. Survival time is primary; points are secondary.

Three lives. False positives cost one life. Misses cost one life and freeze cards
and time for explanation; acknowledgment resumes. Final mistake explains before
results. Normal passage scores10 once; detection scores game danger ×10 (not AWS
severity). Only correct10-point hits receive120ms hitstop. Active time freezes
during hitstop, explanations, explicit/background pause. Untimed study has no timer.

Initial incoming interval1.2s (was4.5s), fall12s (was18s). Active elapsed time
increases pressure independently of score: at180s new falls5.49s/interval338ms,
at300s4.59s/289ms. Readability asymptotes4.2s/280ms. No five-level ceiling or
mandatory three-minute ending. Levels advance every15 active seconds. Human average
survival has not been measured. Tall desktop6cards, tall phone4; short fields3/2.
Two per lane, finite arrivals, upper cards directly tappable. Height-only browser chrome changes continue where cards fit. Orientation changes
pause and safely remap; if the field cannot fit live cards, the frozen round is
retained until a readable size returns. Restart/results remain explicit options;
live objects are never silently removed. The recorded original showed4cards at6.6s and10DOMcards at13.3s.
Our50-seed first12s model benchmark reduced mean empty time3.21s→0.70s;
at6.6s no-input display2→6desktop/4phone. These are not human-play measurements.

First30s:7 obvious parameter cases. From30s the pool broadens; from90s subtle
trust/actor/task/change-context cases join. Each six-item outcome bag is balanced.
Required evidence stays visible. No executable attack/code payloads. Random seeds,
seeded retry, full-pool untimed study, keyboard1–6/Tab/P, reduced motion and background
pause. Only personal best duration is stored locally; unavailable storage is handled.
Times/scores are inspectable casual practice, not certification. X compose is
user-triggered; posting remains theirs. Copy/selectable-text fallback is provided.
