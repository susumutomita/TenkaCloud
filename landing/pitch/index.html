02本日の一番 - StackStack
aws

AI が作った 1 つのアプリ。
ローカルでは動く。

problem: StackStack / 90 min

AI が作り置きしたクラウド設定は穴だらけ。
認証はなし、S3 は公開、ログは残らない、サーバは 1 台。
90 分で、本物のクラウドで安全に動かせ。

1

auth

Basic認証 → SSO

2

network

公開 S3 / 広い IAM → OAC

3

rate

無制限 API → throttle

4

audit

標準出力だけ → WORM

5

uptime

EC2 1 台 → Multi-AZ

“動く” から “出していい” までの距離 -
認証・公開範囲・監査・可用性が、そのまま採点項目になる。

03ゲームデザイン

クラウドに上げて、穴を塞ぎ、

1

クラウドで起動

ローカルでしか動かない AI 製アプリを、まず本物のクラウドで動かす。

2

穴を塞ぐ

公開範囲・権限・認証を直し、本番品質の守りを作る。

3
DB 誤削除サイト改ざんバックドア

インシデント対応

本番 DB の誤削除、サイト改ざん、攻撃を止めずに捌く。

4

サイトを稼働させ続けると得点を獲得

稼働を守り切れたか、対応はどれだけ速かったか。順位が確定する。

勝つのは、何が起きても サイトを稼働させ続けた チーム。
