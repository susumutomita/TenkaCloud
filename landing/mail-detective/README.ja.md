# メールの間違いさがし

`/mail-detective/` の静的ミニゲーム。2 通の架空メールを比較し、危険につながる違いをタップします。開いたら即プレーで、講義・登録・事前クイズはありません。1 回は最大 2 場面、1〜3 分の設計目安です。人の所要時間・実機・学習効果は未検証です。

## 段階と文面

| Lv | 既存ケース | 探す危険箇所 |
| --- | --- | --- |
| 1 | 予約の案内 | 予定にない添付、1 か所 |
| 2 | 請求のお知らせ | 別の差出人・コード返信要求、2 か所 |
| 3 | 共有資料 | 実リンク先・アプリ実行を求める添付、2 か所 |
| 4 | アカウント確認 | 保護解除要求・ツール・返信先、3 か所 |
| 5 | 似た文字のドメイン | 差出人・行き先・コード要求、3 か所 |

元の 5 ケースは保持し、レベルごとの表示用データを生成します。まだ教えていない危険箇所は、受信メールの値も確認済みと同じに戻します。採点対象だけを隠すことはしません。日時や件名、登録済み差出人の違い、公式サイト内のパス変更は正常な例です。Lv2 には、予定どおりの同じ明細 PDF も置きます。違うだけで危険、添付があるだけで悪性とはしません。

各レベルに 3 種類の架空ブランド・依頼文・ファイル名等を用意します。対応するアドレスや確認情報も揃え、再挑戦では直前の同じ文面を避けます。乱数を注入して再現可能です。外部 AI 生成や API は使いません。レベル順は教える順序を守ります。

Lv1〜2 の結果から、任意で Lv3〜4、最後に Lv5 へ進めます。全段階の連続プレーを強制しません。再挑戦は同じ開始レベルの別文面です。発見・解説で確認した数を分け、実際に見た場面だけを分母にします。時間切れや途中終了から次の段階へは進めません。

## 操作と解説

PC は 2 通を並べ、スマホは全幅で切り替えます。Gmail らしい件名・差出人・宛先・時刻・本文の構造を保ち、詳細は折り畳みます。安全な本文や宛先も同じボタンで選べ、候補だけの点線・ホバー装飾はありません。通常リンクの下線とキーボードの見えるフォーカスは保ち、正解表示は回答または答え合わせの後だけです。

押した後に短い理由を示し、詳細は任意です。添付・ツールでは、実行を促す手口、狙われた行動、ダウンロード・実行せず既知の別経路で確認すること、業務なら組織の窓口への報告を説明します。拡張子だけで悪性と断定しません。正解演出は短く、減動作設定を尊重します。

終了時の確認項目も習った範囲から表示します。差出人・行き先・要求・独立経路から始め、Lv4 で認証、Lv5 で似た文字の解説が加わります。初級に DKIM の理解は要求しません。

## ヘッダーと文字の比較

Lv4 以降の「元のメッセージを見る」は、初期状態で閉じた模擬ヘッダー抜粋です。信頼済み受信側 mx.practice.example による観測結果として、From、Reply-To、`Return-Path`、SPF、DKIM、DMARC の整合を示します。実際の DNS 問合せや暗号検証はしません。同名ヘッダーだけでは信頼できず、Reply-To は DMARC の整合対象ではありません。署名値は省略し、X-Practice-DKIM-Domain は有効な DKIM-Signature ではありません。

データには、転送で SPF fail でも整合する DKIM pass により DMARC pass となる反例、別ドメインの SPF/DKIM pass では整合しない例、似た別ドメイン自身の認証は全て pass となる例を含めます。pass は善意・無害の保証ではなく、fail だけでも詐欺と断定しません。

Lv5 の回答後にだけ、実データから文字差分・位置・Punycode を計算して拡大表示します。現在の 3 文面は Latin a（U+0061）から Cyrillic а（U+0430）への置換です。minаmo.example は 4 文字目、nаgisa.example と hаrumi.example は 2 文字目です。元と置換後の文字名、該当位置、ASCII 表記を示します。

比較文字には元のメール要素の computed font-family・weight・style を使います。画面には表示指定を示し、端末の実際の fallback を特定できるとは書きません。同じ文字の字体差と、別の Unicode 文字への置換を分け、国際化ドメイン自体を危険扱いしません。

## 猶予と任意の次の一歩

本文は動かず、メール枠が自動処理の出口へ近づきます。別ゲージ・残秒数字・点滅はありません。各場面は表示されたプレー時間で 60 秒。アドレス・リンク・模擬ヘッダー・回答理由・スマホの比較元閲覧中は停止し、「閉じて続ける」で再開します。非表示・フォーカス喪失・1 秒を超える停止フレームを除外し、期限後の入力を加点しません。時間切れには見逃した箇所、結果共有、すぐ再挑戦を示します。実際のメール配信仕様を再現する演出ではありません。

結果の隣の X 共有は、実際の発見数・確認数、見たレベル、途中終了／時間切れ、本番 URL の投稿文を開くだけです。投稿は本人が確定します。自動投稿・アカウント連携・ネタバレ・能力認定はありません。

両ゲームは同じテーマ一覧へ戻れます。実践には実在する問題説明と、対応するローカル／クラウドの主催者手順を付け、参加者の招待案内と分けます。メールと同テーマの実践は draft のため準備中です。ゲーム単独の再挑戦に登録や開催設定を要求しません。競技機能・認証・LP の別 PR は変更しません。

## 安全・確認方法

メール・ブランド・アドレス・添付は全て架空。メール内のリンクやファイルは静的表示だけで、送信・ダウンロード・実行・AWS 操作をしません。外部 API・資格情報・登録・Docker・計測は不要です。採点値はクライアントから見える学習用で、能力や資格の認定ではありません。公式参照・一覧・共有には本人操作で移動できます。

```sh
bun test scripts/landing/mail-detective.test.ts scripts/landing/mail-levels.test.ts scripts/landing/mail-next-step.test.ts
bun run stamp:landing-assets
python3 -m http.server 19980 --bind 127.0.0.1 --directory landing
```

同じ Mac だけで `http://127.0.0.1:19980/mail-detective/?lang=ja` を開きます。英語は lang=en。既存サーバーが起動中なら重複起動しません。本番公開とは別です。

公式根拠は [FTC](https://consumer.ftc.gov/articles/how-recognize-avoid-phishing-scams)、[Gmail](https://support.google.com/mail/answer/180707)、[RFC8601](https://www.rfc-editor.org/rfc/rfc8601)、[RFC9989](https://datatracker.ietf.org/doc/html/rfc9989)、[RFC5890](https://www.rfc-editor.org/rfc/rfc5890)、[UnicodeUTS39](https://www.unicode.org/reports/tr39/)、[Unicode文字データ](https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt)。ケースと UI は独自の架空教材です。今後の体系は[学習経路](../../docs/learning-path/README.ja.md)を参照します。

採点：怪しい箇所を回答して正解なら＋1、正常・変更なしの箇所を怪しいと回答すると−1。各箇所は一度だけ計上します。差出人・ヘッダー・リンク先の開閉、比較タブ切替、キーボード移動は調査なので減点しません。結果と任意の X 共有には実得点とミス数を示し、答えを見る操作では加点しません。
