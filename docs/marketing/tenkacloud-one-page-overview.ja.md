# TenkaCloud One-Page Overview (Japanese)

AI 時代のクラウド / セキュリティ演習基盤。座学だけでなく、実環境を運用・破壊・防御・復旧しながら学ぶための OSS プラットフォームです。

| 項目 | 内容 |
| --- | --- |
| TenkaCloud とは | AWS GameDay のようなクラウド / セキュリティ演習を再利用可能なイベントとして運営するための OSS です。主催者はチーム・問題・スコア・ヒント・監査ログをまとめて扱えます。 |
| なぜ今か | AI 開発、クラウド運用、セキュリティ対応は講義だけでは身につきません。障害や攻撃の兆候を見つけ、判断し、復旧する経験が必要です。 |
| 解決する課題 | 実践型の演習は効果が高い一方で、毎回の環境準備や採点、進行管理、後片付けが重くなりがちです。TenkaCloud はその運営負荷を下げ、学習体験を再利用しやすくします。 |
| 主催者ができること | AWS GameDay 風の演習開催、チーム別環境の配布、スコア・ヒント・進捗・監査ログの確認ができます。研修、勉強会、BootCamp、採用評価、障害対応訓練にも使えます。 |
| ユースケース | 社内クラウド研修、セキュリティ勉強会、SRE / DevOps 演習、CCoE 育成、AI エージェント運用ベンチマーク、短時間のミニ GameDay に向いています。 |
| Raycast 連携の角度 | Raycast は TenkaCloud 運営者の高速なコマンド面になれます。イベント作成、問題デプロイ、チーム状態確認、スコア確認、ヒント配布、障害注入、AI による状況要約を Raycast から呼び出す構想です。 |
| 最初の共同企画 | 「1 時間のミニ GameDay + Raycast 運営コマンドの小さなデモ」がよい候補です。参加者は壊れたクラウドを直し、主催者は Raycast で進行を確認します。 |
