TenkaCloud 15-Second Elevator Pitch

This document keeps short, non-salesy introductions for TenkaCloud that fit Slack, meetups, and quick 1:1 introductions.

Core Pitch

Core Pitch (Japanese)

TenkaCloud は AWS GameDay のようなクラウド / セキュリティ演習を OSS で運営するためのプラットフォームです。講義を聞くだけでなく、実際のクラウド環境を運用・破壊・防御・復旧しながら学べます。

Core Pitch (English)

TenkaCloud is an OSS platform for running AWS GameDay-like cloud and security exercises. Instead of learning from lectures alone, teams operate, break, defend, and recover real cloud environments.

Slack Introduction

Slack Introduction (Japanese)

TenkaCloud は、AWS GameDay のようなクラウド / セキュリティ演習を OSS で運営するためのプラットフォームです。AI 開発者やクラウド学習者が、実環境の運用・破壊・防御・復旧を短い演習として体験できます。

Slack Introduction (English)

TenkaCloud is an OSS platform for running AWS GameDay-like cloud and security exercises. It gives AI developers and cloud learners a practical way to operate, break, defend, and recover real environments in a short exercise format.

Meetup Self-Introduction

Meetup Self-Introduction (Japanese)

TenkaCloud という OSS を作っています。AWS GameDay のように、参加者が実際のクラウド環境を運用・破壊・防御・復旧しながら学べるクラウド / セキュリティ演習プラットフォームです。

Meetup Self-Introduction (English)

I build TenkaCloud, an OSS platform for AWS GameDay-like cloud and security exercises. It helps people learn by operating, breaking, defending, and recovering real cloud environments, not just by listening to talks.

Usage Notes

Use the core pitch when there is only one breath available. Use the Slack version when introducing the project to AI developer communities. Use the meetup version when the speaker is introducing their own work.
