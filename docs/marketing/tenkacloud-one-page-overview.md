# TenkaCloud One-Page Overview

TenkaCloud is an OSS platform for cloud and security exercises in the AI era. It helps people learn by operating, breaking, defending, and recovering real environments, not just by listening to lectures.

| Section | Overview |
| --- | --- |
| What is TenkaCloud? | An OSS platform for running reusable AWS GameDay-like cloud and security events. Organizers can manage teams, problems, scoring, hints, progress, and audit logs in one operating model. |
| Why now? | AI development, cloud operations, and security response are operational disciplines. Teams need realistic practice where they detect signals, make decisions, communicate under pressure, and recover systems. |
| What problem does it solve? | Hands-on exercises work, but repeated event setup, scoring, team coordination, safety boundaries, and teardown often become custom work. TenkaCloud reduces that operational load. |
| What can organizers do with it? | Run AWS GameDay-like exercises, give each team an isolated practice environment, track progress, and use the format for training, study groups, BootCamps, hiring evaluation, and incident drills. |
| Example use cases | Internal cloud training, security study groups, SRE / DevOps exercises, CCoE enablement, AI agent operations benchmarks, and short mini GameDays. |
| Raycast collaboration angle | Raycast could become a fast operator command surface. Operators could create events, deploy challenges, check team status, inspect scores, distribute hints, inject incidents, and ask AI to summarize event state. |
| Suggested first collaboration | Start with a 1-hour mini GameDay plus a small Raycast operator-command demo. Participants fix a broken cloud scenario while organizers use Raycast to monitor progress. |

## Next Step

Run one small event together, observe which audience understands it fastest, and decide whether to expand into a recurring cloud/security exercise format.
