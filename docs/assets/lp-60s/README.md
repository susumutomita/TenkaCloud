## 画面の出どころ

画面は、1 台のマシンで起動した実物を 2 回に分けて撮影したものです。どちらの回も、問題カタログは TenkaCloudChallenge `a7a9cfe`、Simulator は TenkaCloudSimulator `36e72c4` をソースから `make build` したもので、`--simulator-endpoint` と `--simulator-bootstrap` で接続しています。大会は Tenka Battle Cup 2026 (Hello World、3 チーム) です。動画側の加工は、切り出し、拡大、枠による強調だけです。

- 13〜26 秒の参加者ポータル：2026-11-10 (UTC)、TenkaCloud `f5783ac`。ブラウザの窓にページ全体を映したもの。1 チームはヒントを 1 つ開いて 80 pt、もう 1 チームはヒントなしで 100 pt。
- 26〜48 秒の主催者画面と Simulator の画面：2026-11-11 (UTC)、TenkaCloud `17002de`。操作する部分だけを切り出して拡大したもの。

主催者キー、チームキー、Simulator のトークンは映していません。参加者ポータルの Flag 欄は伏せ字です。Simulator のパラメータ画面に出る値 (解答) は、この収録だけで使ったローカルの値で、伏せていません。

## 実画面ではないもの

- 28〜32 秒のターミナル：`make local` の実際の出力行を抜粋し、文字として組んだもの。主催者キーの行は含めない。
- 15〜17 秒の Flag 欄の入力：入力済みの実画面を 4 文字ずつ見せて、入力の様子を表したもの。
- 背景の城・雷雲・金の筆致：書籍『自分で作るクラウド競技』の表紙絵を 4 倍に拡大したもの。拡大には Real-ESRGAN を使っており、細部には元絵と一致しない箇所がある。
- 音楽と効果音：この動画のために合成したもの。既存の楽曲や音源は不使用。

## この動画が示していないこと

- Docker 問題は含まない。収録環境に Docker がなかったため。
- 実 AWS への配置は含まない。Simulator で動かしたのは Hello World の 1 問で、Simulator 連携の検証対象もこの 1 問。
- Simulator の場面は、AWS の Parameter Store の値を読む操作。ほかのクラウドの場面は含まない。
- Simulator は開発中で未リリース。独立したシミュレーターで、各クラウドの公式のものではない。

## 検証

- ffmpeg で全フレームをデコードし、エラーがないことを確認。
- 全場面の連番シートを目視で確認。文字と画面が枠の外へ切れていないことを、配置の検査で確認。
- 統合ラウドネスは −14.5 LUFS、トゥルーピークは −1.7 dBFS。フルスケールに達したサンプルはなし。
- 音のアクセントは拍から 16 ms 以内。
- 収録者は音を聴いておらず、確認は測定のみ。完成版は所有者が確認し、公開を承認した。
