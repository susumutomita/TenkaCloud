01 — Marks

3 つのマーク案

いずれも単色・幾何学ベースで、極小サイズでも崩れず、商標として識別性が高い設計です。推奨は「Summit」。

Primary

Summit

天 ＋ 頂（いただき）
漢字 「天」 の上線と、頂上へ伸びる稜線を抽象化。稜線の底辺：高さ = 1.618（黄金比 φ）、上線の幅も底辺と同幅で揃えている。天下＝頂点を獲るという名前の意味と、競技で登りつめる感覚を1つの形に。

Ascend

ランク章 / 昇格
積み重なる山形は階級章のモチーフ。ランクが上がるゲーム性をストレートに表現。動きの拡張（段が増える演出）にも向く。

Cloudpeak

雲 ＋ 頂
雲（クラウド）の上に頂が突き抜ける構図。プロダクトの「クラウド」を最も直接的に示すが、形はやや複雑。
