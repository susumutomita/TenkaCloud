# TenkaCloud 参加者ガイド

TenkaCloud GameDay に参加するためのガイドです。GameDay は AWS セキュリティをテーマにしたチーム対抗の競技イベントです。攻撃と防御を通じて、実践的なクラウドセキュリティスキルを身につけましょう。

## 参加方法

### アカウント登録とログイン

1. Application Plane（`http://localhost:13001`）にアクセスする
2. 「サインアップ」からアカウントを作成する
3. メールアドレスとパスワードでログインする

### チームへの参加

GameDay には 3 つの参加方法があります。

**チームを作成する場合**

1. GameDay のイベントページを開く
2. 「チーム作成」を選択する
3. チーム ID とチーム名を入力する
4. 作成後に表示される招待コードをチームメンバーに共有する

**既存のチームに参加する場合**

1. GameDay のイベントページを開く
2. 「チーム参加」を選択する
3. チームリーダーから共有された招待コードを入力する

**ソロで参加する場合**

1. GameDay のイベントページを開く
2. 「ソロ参加」を選択する

### チーム URL の設定

ゲーム開始前に、チームの Web サイトと API の URL を設定してください。

1. 司令部（Headquarters）ページを開く
2. 「URL 設定」セクションで以下を入力する
   - Web サイト URL: チームの Web サイトのアドレス
   - API URL: チームの API エンドポイントのアドレス
3. 「保存」をクリック

これらの URL はヘルスチェックの対象になります。URL が未設定の場合、ヘルスチェックのペナルティは発生しません。

## ゲームのルール

### スコアリングシステム

ゲーム開始時に各チームに **10,000 ポイント** が付与されます。以下の行動でポイントが変動します。

| 行動 | ポイント |
|---|---|
| 攻撃を購入する | -3,000 |
| 攻撃に成功する | +1,000 |
| 攻撃を受ける | -1,000 |
| 攻撃を防御する（脆弱性修正済み） | +1,000 |
| 脆弱性を修正する | +1,500 |
| ヘルスチェックに合格する（60 秒ごと） | +100 |
| ヘルスチェックに失敗する（通常モード） | -100 |
| ヘルスチェックに失敗する（高倍率モード） | -1,000 |
| ヒントを購入する | -500 〜 -3,000 |
| 投票を受ける | +5,000 |

### 攻撃

攻撃はポイントを消費して購入し、他チームに対して実行します。

**攻撃の手順**

1. 攻撃カタログから攻撃を選ぶ
2. 3,000 ポイントを支払って攻撃を購入する
3. 攻撃対象のチームを選択して実行する

**攻撃の種類**

攻撃には 2 つの種類があります。

- **脆弱性悪用型**: 特定の脆弱性を狙う攻撃である。対象チームが脆弱性を修正済みの場合、攻撃は失敗する
- **カオス型**: インフラ障害をシミュレートする攻撃である。脆弱性���修正では防御できない

**クールダウン**

攻撃した後、同じ攻撃を再び使用するには **300 秒（5 分）** のクールダウン時間が必要です。

**同盟による報酬分配**

同盟を結んでいるチームがある場合、攻撃成功時の報酬は同盟メンバー間で均等に分配されます。

### 防御

自チームの脆弱性を修正して、攻撃から身を守ります。

**脆弱性の修正**

1. 防御塹壕（Defense Trench）ページを開く
2. 受けている攻撃の一覧を確認する
3. 実際の AWS 環境で脆弱性を修正する
4. 修正が完了したら「修正報告」を実行する
5. 修正が成功すると **+1,500 ポイント** が付与される

**ヒントの購入**

脆弱性の修正方法がわからない場合、ヒントを購入できます。

- ヒントのコストは攻撃ごとに異なる（0 〜 3,000 ポイント）
- SQL Injection と Remote Code Execution のヒントは無料
- それ以外のヒントは 3,000 ポイント

### 同盟

他のチームと協力関係を築くことができます。

**同盟の申請**

1. 同盟ページを開く
2. 同盟を組みたいチームを選択する
3. 「同盟申請」をクリック

**同盟の承認**

1. 受信した同盟申請を確認する
2. 「承認」をクリックして同盟を成立させる

**同盟の効果**

- 攻撃成功時の報酬が同盟メンバー間で分配される
- 同盟はいつでも破棄できる

### 投票

ゲーム中に他のチームに投票できます。

- 各チームは 1 回だけ投票可能
- 自分のチームには投票できない
- 投票されたチームは **+5,000 ポイント** を獲得する

### ヘルスチェック

運営が 60 秒ごとに全チームの Web サイトと API のヘルスチェックを実施します。

- HTTP ステータスコード 200 番台で正常とみなされる
- レスポンスのタイムアウトは 10 秒
- 正常なら +100 ポイント、異常なら -100 ポイント（通常モード）
- ゲーム終盤に「高倍率モード」が有効になると、異常時のペナルティが -1,000 ポイントに増加する

### ブラックアウト

ゲーム残り 30 分になると、リーダーボードが自動的に非表示になります。最終結果はゲーム終了後に発表されます。

## 戦略のヒント

### 攻守のバランスを取る

- 攻撃の購入には 3,000 ポイントが必要だが、成功報酬は 1,000 ポイント
- 脆弱性の修正は 1,500 ポイントの報酬がある
- まず自チームの脆弱性を修正してから攻撃に出るのが安定した戦略

### ヘルスチェックを維持する

- 60 秒ごとに +100 ポイントが加算される
- 1 時間のゲームで最大 6,000 ポイントをヘルスチェックだけで稼げる
- サービスがダウンしないよう常に監視する

### 同盟を活用する

- 同盟を結ぶと攻撃報酬が分配されるが、1 人あたりの取り分は減る
- 信頼できるチームと同盟を組み、攻撃対象を分担するのが効果的
- 同盟は状況に応じて破棄できる

### 脆弱性を早く修正する

- 脆弱性が修正されていれば、脆弱性悪用型の攻撃を自動で防御できる
- 防御に成功すると攻撃者ではなく防衛者に +1,000 ポイントが入る
- 修正自体にも +1,500 ポイントの報酬がある

### 高倍率モードに備える

- ゲーム終盤にスコア重みが「高倍率」に切り替わることがある
- ヘルスチェック異常時のペナルティが 10 倍に増加する
- 終盤はサービスの安定性維持を最優先にする

## 画面の使い方

### 司令部（Headquarters）

チームのダッシュボードです。以下を確認・設定できます。

- チームの Web サイトと API のヘルスチェック状態
- ヘルスチェック履歴（直近 10 件）
- 最近の攻撃履歴（直近 8 件）
- チームの URL 設定

### 攻撃ステーション（Attack Station）

攻撃を購入・実行する画面です。

- 攻撃カタログ: 利用可能な攻撃の一覧
- 攻撃購入: ポイントを支払って攻撃を入手する
- 攻撃実行: 対象チームを選んで攻撃する
- 攻撃履歴: 自チームが実行した攻撃の結果

### 防御塹壕（Defense Trench）

防御に関する画面です。

- 受けている攻撃の一覧
- ヒントの購入
- 脆弱性の修正報告

### スコアボード（Scoreboard）

リーダーボードと統計情報を表示します。

- チーム別のスコアランキング
- 各チームの攻撃実行数・被攻撃数
- 攻撃種別ごとの実行回数と成功率
- ブラックアウト中はスコアが非表示になる

### 同盟（Alliance）

同盟の管理画面です。

- 同盟の申請
- 受信した同盟申請の承認
- 同盟の破棄

### 投票（Vote）

他チームへの投票画面です。

- チーム一覧から投票先を選択する
- 投票結果の閲覧
